OPTION 2: THREE-NODE SETUP (20 minutes)

STEP 1: Start Node A (Terminal 1)
├─ Command: ./build/node interactive --initial-balance 5000 --port 30333
├─ Wait for: Peer ID
└─ Copy: [PEER_ID_A]

STEP 2: Start Node B (Terminal 2)
├─ Command: ./build/node interactive --initial-balance 5000 --port 30334 \
│   --bootstrap /ip4/127.0.0.1/tcp/30333/p2p/[PEER_ID_A]
└─ Result: Connected Peers: 1 ✓

STEP 3: Start Node C (Terminal 3)
├─ Command: ./build/node interactive --initial-balance 5000 --port 30335 \
│   --bootstrap /ip4/127.0.0.1/tcp/30333/p2p/[PEER_ID_A]
└─ Result: Connected Peers: 1 ✓

STEP 4: Register All Three (in each terminal)
├─ T1: > register-validator --stake 1500
├─ T2: > register-validator --stake 1500
└─ T3: > register-validator --stake 1500

STEP 5: Verify Consensus
T1: > validators
├─ Should show 3 validators (A, B, C)
├─ All with Status: active
└─ Ranks: 0, 1, 2

STEP 6: Watch Block Production
├─ T1: > status → Block Height: 0, Connected Peers: 2
├─ [Wait 10 seconds]
├─ T2: > status → Block Height: 1, Connected Peers: 2
├─ [Wait 10 seconds]
└─ T3: > status → Block Height: 2, Connected Peers: 2

BLOCK PRODUCTION PATTERN:
├─ Block 0→1: Node A produces (Rank 0)
├─ Block 1→2: Node B produces (Rank 1)
├─ Block 2→3: Node C produces (Rank 2)
├─ Block 3→4: Node A produces (Rank 0) ← cycles
└─ ✅ ROUND-ROBIN CONSENSUS WORKING!

STEP 7: Test Full Mesh Transfers
├─ A→B: > transfer --to [B_ADDR] --amount 300
├─ B→C: > transfer --to [C_ADDR] --amount 300
└─ C→A: > transfer --to [A_ADDR] --amount 300

STEP 8: Verify All Nodes See Updates
├─ T1: > balance [A_ADDR] → 4800 (5000 - 1500 stake + 300 from C)
├─ T2: > balance [B_ADDR] → 4800 (5000 - 1500 stake + 300 from A)
└─ T3: > balance [C_ADDR] → 4800 (5000 - 1500 stake + 300 from B)

OPTION 3: FOUR-NODE SETUP (30 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Start Four Nodes in Sequence:

T1 (Node A, port 30333):
  $ ./build/node interactive --initial-balance 5000 --port 30333
  [Copy PEER_ID_A]

T2 (Node B, port 30334):
  $ ./build/node interactive --initial-balance 5000 --port 30334 \
    --bootstrap /ip4/127.0.0.1/tcp/30333/p2p/[PEER_ID_A]

T3 (Node C, port 30335):
  $ ./build/node interactive --initial-balance 5000 --port 30335 \
    --bootstrap /ip4/127.0.0.1/tcp/30333/p2p/[PEER_ID_A]

T4 (Node D, port 30336):
  $ ./build/node interactive --initial-balance 5000 --port 30336 \
    --bootstrap /ip4/127.0.0.1/tcp/30333/p2p/[PEER_ID_A]

Register All Four:
  All terminals: > register-validator --stake 1200

Verify All Connected:
  T1: > status
      Connected Peers: 3 ✓
      Block Height: 0

Monitor Block Production:
  [After 10 seconds]
  > status
  Block Height: 1

  [After 20 seconds]
  > status
  Block Height: 2

  [After 30 seconds]
  > status
  Block Height: 3

  ✅ 4-NODE NETWORK CONSENSUS WORKING!

Network Diagram:
  T1 (Node A) ←→ T2 (Node B)
       ↓  ↗
       ↓/
  T4 (Node D)←→ T3 (Node C)

Expected Result:
  Block Height: Synchronized across all 4 nodes
  Validators: All 4 visible in all nodes
  Connected Peers: Each node shows 3
  Block Time: ~10 seconds between blocks
  No crashes or errors

ISSUE: Nodes won't connect
FIX:   Check bootstrap address format
       Correct: /ip4/127.0.0.1/tcp/30333/p2p/12D3KooWxxx...
       Wrong:   12D3KooWxxx... (missing /ip4/127.0.0.1/tcp/PORT)

ISSUE: Port already in use  
FIX:   Use different ports for each node
       Node A: --port 30333
       Node B: --port 30334
       Node C: --port 30335
       Node D: --port 30336

ISSUE: Blocks not being produced
FIX:   Register as validator first
       > register-validator --stake 1000
       Then wait 10+ seconds

ISSUE: Validators not showing on other nodes
FIX:   Wait 5 seconds for propagation, then check again
       > validators

ISSUE: Transfer doesn't work
FIX:   Use full address from balance command
       > balance           (get your address)
       > transfer --to [ADDRESS] --amount 100
